# Contributing to Embedito95

Embedito95 does not accept external pull requests.

The project is dual-licensed (AGPL-3.0-only and commercial), and accepting code
from outside contributors would require a signed CLA to keep that possible.
Until that process exists, the repository stays closed to outside code changes.

## What is welcome

- **Issues**: bug reports, ideas, documentation errors, feature requests.
- **Reproductions**: a minimal `.e95` project or a few lines that show the bug.
- **Board reports**: what you tested, what worked and what did not.

A good issue answers:

1. What did you run? (command, board, e95 version)
2. What did you expect?
3. What happened instead? (full output, including compiler errors)
4. Minimal code to reproduce it.

## What is not accepted

- Pull requests with code, even small fixes.
- Forks published as an improved Embedito95.
- Patches sent by email or chat.

An issue that points to a bug in a specific line is fine. The change itself is
made in this repository.

## Using Embedito95

You can fork it, read it and modify it for your own use under the AGPL. If you
distribute firmware built with it, or a modified version of the toolchain, the
AGPL applies. See [LICENSE](LICENSE) and [LICENSE-COMMERCIAL.md](LICENSE-COMMERCIAL.md).
