# embedito95-registry

Platforms, strategies, core libraries and C++ templates for **Embedito95**
(language `e95`).

This package ships the source of the platforms (`arduino-nano`, `arduino-uno`,
`stm32-bluepill`), the built-in libraries and the templates used by the
compiler. It is used by
[`embedito95-cli`](https://www.npmjs.com/package/embedito95-cli) and is not meant
to be used directly.
