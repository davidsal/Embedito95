# embedito95-core

Compiler and code-generation core for **Embedito95** (language `e95`).

Contains the lexer, parser, type checker and C++ code generation. It is used by
[`embedito95-cli`](https://www.npmjs.com/package/embedito95-cli) and is not meant
to be used directly.
