# Embedito95 Language Support

Language support for **e95**, the Embedito95 language: a small TypeScript-like
language for microcontrollers that compiles to C++.

Features:

- Syntax highlighting for `.e95` files
- Diagnostics and type errors
- Hover with types, signatures and library documentation
- Completions for the language and hardware libraries
- Semantic tokens

The language server is bundled in the extension; there is nothing else to
install.
