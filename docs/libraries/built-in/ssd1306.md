# SSD1306

OLED display over I2C or SPI.

```e95
import { getDisplayI2C } from '@embedito95/ssd1306'
import { I2C } from '@embedito95/i2c'

const display = getDisplayI2C(I2C.1)
```

| API | Description |
| --- | --- |
| `getDisplayI2C(i2c: I2C): Ssd1306Display` | Creates a display on an I2C bus. |
| `getDisplaySPI(spi: SPI, cs: Pin, dc: Pin): Ssd1306Display` | Creates a display on an SPI bus with chip-select and data/command pins. |

## Ssd1306Display

| API | Description |
| --- | --- |
| `initialize(): void` | Configures the panel. |
| `clearDisplay(): void` | Clears the screen. |
| `setCursor(x: u16, y: u16): void` | Moves the text cursor. |
| `setTextScale(scale: u8): void` | Sets the text size multiplier. |
| `write(text: string): void` | Draws text at the cursor. |

Glyph data comes from `@embedito95/canvas`.
