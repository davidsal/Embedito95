# MAX7219

8x8 LED matrix driven by a MAX7219 controller over SPI.

```e95
import { getMatrix } from '@embedito95/max7219'
import { getSPI, SPI } from '@embedito95/spi'
import { Pin } from '@embedito95/gpio'

const matrix = getMatrix(SPI.1, Pin.10)
```

| API | Description |
| --- | --- |
| `getMatrix(spi: SPI, cs: Pin): LedMatrix` | Creates a matrix handle on the bus and chip-select pin. |
| `initialize(): void` | Starts the controller and clears the display. |
| `clear(): void` | Turns every pixel off. |
| `setPixel(x: u8, y: u8, on: boolean): void` | Sets one pixel; `(0, 0)` is the top-left corner. |
| `setRow(row: u8, value: u8): void` | Writes a full row; the most significant bit is the leftmost pixel. |
| `drawImage(bitmap: u8[]): void` | Draws eight row bytes, top row first. |
| `setIntensity(intensity: u8): void` | Sets brightness from `0` to `15`. |
